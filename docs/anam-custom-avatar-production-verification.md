## 원인 해석

Gemini 검사 단계 실패나 확정된 계정·비용 제한 응답이 아니다.
이미지 생성 단계는 성공했고, 오류는 Anam 생성 요청의 전송·응답 구간이다.
제공자 HTTP 상태는 수신·보존되지 않았으므로 401·402·403·429 등의 거절로 단정할 수 없다.

어댑터의 생성 HTTP 제한은 30초이며 이미지 단계 성공부터 실패까지 약 30초다.
Anam 자원의 생성 시각은 라우터 실패보다 늦다.
따라서 **동기 생성의 30초 응답 제한 이후에도 제공자 처리가 계속된 상황이 유력**하다.
하지만 현재 오류 기록이 타임아웃·연결 실패 등을 구분하지 않아
최초 예외가 정확히 타임아웃이었는지는 확정하지 못한다.

- 라우터: 결과 확인 필요, 제공자 ID 없음, 완료 메시지 없음.

- 자원을 추가 생성하지 말아야 하며 현재 결과 불명 차단을 우회하지 않는다.

  승인된 조정 경로로 기존 자원을 연결해야 한다. 임의 ID 추정·삭제는 금지한다.
- 재발 방지는 Anam 생성의 응답 대기·작업권·늦게 도착한 ID 보존을 함께 다뤄야 한다.
  단순 자동 재시도나 실패 상태 해제로 해결하지 않는다.
