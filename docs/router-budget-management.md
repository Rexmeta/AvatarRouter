# 라우터 예산 조정·사용 카운터 초기화

## 세션별 준비·영상 시간

예산의 `usedSeconds`는 영상 재생 시간으로 바꾸지 않는다. 세션별 `timing`에서 준비 시간과 첫 영상 보고 이후 시간을 별도로 표시한다. 보고가 없는 기존 기록은 미확인으로 유지한다. 자세한 계약은 [라이브 시간 관측](session-video-timing.md)을 참고한다.

## 사용 시간과 임시 확보 시간

`usedSeconds`는 최대 대화 시간이 아니라 준비 시간을 포함한 라우터 세션 경과 시간입니다. 종료 요청·종료·만료 중 가장 이른 시점까지 계산하고 예약 상한을 넘지 않습니다. 실제 발화 시간이나 제공자 청구액을 의미하지 않습니다.

`reservedSeconds`는 진행 중이거나 정리 결과가 불확실한 세션이 임시 확보하는 미사용분입니다. 잔여 한도는 `dailySeconds - usedSeconds - reservedSeconds`입니다. 정리가 확인된 45초 세션은 최대 시간이 600초여도 45초만 사용 처리하며, 미사용 555초는 확보분에서 해제됩니다. 제공자 생성이 시작되지 않았거나 명시적으로 거절됐고 제공자 ID도 없으면 사용 시간은 0입니다.

기존 예약 원본이나 세션을 덮어쓰지 않고 조회 시 계산합니다. 기존 종료 시각이 남아 있는 세션도 새 계산을 적용받습니다. 확인되지 않은 종료는 사용량 표시와 별개로 새 연결·초기화 차단을 유지합니다.

## 사용자 화면

로그인 → Account → Workspaces → 해당 워크스페이스 → **Usage & limits**.

- 프로젝트 소유자는 자기 프로젝트의 하루 라이브 예약 예산을 분 단위로 저장할 수 있습니다.
- 서비스 전체 예산은 일반 사용자에게 조회 전용이며, 기존 신뢰 운영자 권한이 있는 계정만 변경·초기화할 수 있습니다.
- 0분은 새 연결을 중지합니다. 진행 중인 세션을 강제로 종료하지 않습니다.
- 프로젝트 예산은 서비스 전체 일일 예산을 초과할 수 없습니다.
- 저장에는 비용 증가 가능성에 대한 명시적 확인이 필요합니다.
- 자동 일일 초기화는 UTC 00:00, 한국 시각 오전 9시입니다.

이 예산은 **Tavus 요금제·잔액·실제 청구액이 아닌 AvatarRouter의 연결 허용 예산**입니다.
입력값을 높여도 Tavus 자체의 사용량·계정 제한은 바뀌지 않습니다.
회당 세션 기한은 별도 서버 설정으로 표시됩니다.

## 수동 초기화의 정확한 의미

확인 체크 후 **사용 카운터 초기화**를 누르면 선택한 범위에만 새로운 집계 기준 시각을 기록합니다.
기존 세션·오류·예약 원본·로그와 이전 변경 이력을 삭제하지 않습니다.
Tavus 잔액 충전·환불·유료 사용량 초기화가 아닙니다.

- 프로젝트 초기화는 서비스 전체 사용량을 줄이지 않습니다.
- 서비스 초기화는 각 프로젝트 사용량을 줄이지 않습니다.
- 활성 세션, 불확실 생성 또는 미완료 정리가 해당 범위에 남아 있으면 초기화를 거절합니다.
- 초기화해도 시간당 시도 한도·동시 연결 제한·정리 차단은 유지됩니다.
- 초기화로 추가 유료 사용이 허용될 수 있으므로 별도 동의를 받습니다.

저장과 초기화는 새 세션을 생성하거나 이미지·오디오를 전송하지 않습니다.

## API와 권한

모든 관리 API는 동일 출처의 로그인한 워크스페이스 소유자 전용입니다.
프로젝트 API 키, 위임 토큰, 다른 계정으로 예산을 변경하거나 초기화할 수 없습니다.

- `GET /api/v1/developer/workspaces/{projectId}/budget`
- `PATCH /api/v1/developer/workspaces/{projectId}/budget`
- `POST /api/v1/developer/workspaces/{projectId}/budget/reset`

수정 예:

```json
{"scope":"project","dailySeconds":3600,"revision":0,"costConfirmed":true}
```

초기화 예:

```json
{"scope":"project","revision":1,"confirmed":true}
```

`revision`은 직전 조회 응답을 사용합니다. 동시 수정이나 응답 유실 후 같은 요청을 자동 재전송하지 않습니다.
충돌은 `BUDGET_REVISION_CHANGED`, 미정리 세션은 `BUDGET_RESET_SESSION_UNRESOLVED`로 구분됩니다.
관리 작업은 입장 예약과 같은 데이터베이스 잠금을 사용하고, 변경 전후 값과 수행 주체·시각을 감사 기록으로 남깁니다.

## 이번 운영 한도 요청과 적용 상태

사용자가 승인한 서버 설정: Tavus 회당 600초, 프로젝트 기본 일일 3600초, 서비스 기본 일일 7200초.
각각 `TAVUS_LIVE_SESSION_SECONDS`, `LIVE_USER_DAILY_SECONDS`, `LIVE_GLOBAL_DAILY_SECONDS`입니다.
화면에 저장한 예산은 해당 기본값을 덮어씁니다. 회당 시간은 브라우저 SDK 0.9.2부터 서버 만료 시각을 따릅니다.
Anam의 별도 120초 정책은 변경하지 않았습니다.

새 관리 테이블은 개발 DB에만 추가했습니다. 운영 소스·스키마는 Publish를 통해 함께 반영해야 합니다.
운영 데이터 초기화·기존 세션 복구·유료 생성·운영 게시를 실행하지 않았습니다.
실제 로그인된 화면의 저장·재접속 흐름과 유료 커스텀 영상 재생은 별도 운영 검증 대상입니다.
